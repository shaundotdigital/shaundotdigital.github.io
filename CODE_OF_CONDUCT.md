# Code of conduct

This is a one-person site, but if you open an issue or a pull request, please:

- Be kind and assume good intent.
- Keep comments about the work, not the person.
- Leave out harassment, insults, and sexual or discriminatory language.

I'll remove comments, issues or pull requests that don't meet this, and block repeat offenders.

## Reporting a problem

If someone's behaviour here bothers you, contact me privately through the Email me button at [byshaun.xyz](https://byshaun.xyz/#contact) or on [LinkedIn](https://www.linkedin.com/in/shaunskeen). I'll read every report and keep it private.
