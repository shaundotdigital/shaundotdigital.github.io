# Contributing

This is my personal site, so I'm not looking for new features or design changes. Small fixes are welcome though.

## Good reasons to open an issue

- Something looks broken or doesn't work on your device or browser
- A typo or a dead link
- An accessibility problem, such as poor contrast or something you can't reach with a keyboard

Use one of the [issue templates](https://github.com/shaundotdigital/shaundotdigital.github.io/issues/new/choose) so I have what I need to fix it.

## Pull requests

For a typo or a broken link, feel free to open a pull request straight away. For anything bigger, open an issue first so we can agree on it before you spend time on it.

1. Fork the repo and branch from `dev`. Pull requests go into `dev`, never `live`.
2. Run `npm install`, then `npm run dev` to see your change at `localhost:4321`.
3. Run `npm run check` and `npm run build` before you push. Both should pass.
4. Use UK English in any text you change.
