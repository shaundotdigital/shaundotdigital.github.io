# Security policy

This is a static site with no logins, forms or user data. The only third-party code that runs on it is Google Analytics.

## Supported version

Only the live site at [byshaun.xyz](https://byshaun.xyz), built from the `live` branch, gets fixes.

## Reporting a problem

Please don't open a public issue for a security problem. Report it privately instead:

1. Go to the [Security tab](https://github.com/shaundotdigital/shaundotdigital.github.io/security) of this repo.
2. Click **Report a vulnerability**.

Tell me what you found, where, and how to reproduce it. I'll reply within a week and let you know when it's fixed.
